# Turing Completeの攻略

## キャンペーン用: 32bit CPU

### レジスタ

- `zr`: 零レジスタ
- `r1`: 汎用
- `r2`: 汎用
- `r3`: 汎用
- `r4`: 汎用
- `r5`: 汎用
- `r6`: 汎用
- `r7`: 汎用
- `r8`: 汎用
- `r9`: 汎用
- `r10`: 汎用
- `r11`: 汎用
- `r12`: 汎用
- `r13`: 汎用
- `sp`: スタックポインタ
- `flags`: フラグレジスタ

### 命令セット

- `nop`: 何もしない命令
- `in`: 入力を読み込み、レジスタに格納する命令
- `out`: 出力命令（レジスタや即値を出力する）
- `keyboard`: キーボード入力を読み込み、レジスタに格納する命令
- `screen`: スクリーン設定に値を保存する命令
- `time_0`: 時間値の下位4バイトを読み込む命令
- `time_1`: 時間値の上位4バイトを読み込む命令
- `counter`: カウンタ値を読み込む命令
- `nand`: ビットごとのNAND（否定論理積）演算を行う命令
- `or`: ビットごとのOR（論理和）演算を行う命令
- `and`: ビットごとのAND（論理積）演算を行う命令
- `nor`: ビットごとのNOR（否定論理和）演算を行う命令
- `add`: 加算を行う命令
- `sub`: 減算を行う命令
- `xor`: ビットごとのXOR（排他的論理和）演算を行う命令
- `lsl`: 論理左シフトを行う命令
- `lsr`: 論理右シフトを行う命令
- `asr`: 算術右シフトを行う命令
- `cmp`: 比較を行い、結果をフラグレジスタに保存する命令
- `jmp`: 無条件ジャンプ命令
- `je`: 値が等しい場合にジャンプする命令
- `jne`: 値が等しくない場合にジャンプする命令
- `jb`: 第一引数が第二引数より小さい（符号なし）場合にジャンプする命令
- `jae`: 第一引数が第二引数以上（符号なし）の場合にジャンプする命令
- `jbe`: 第一引数が第二引数以下（符号なし）の場合にジャンプする命令
- `ja`: 第一引数が第二引数より大きい（符号なし）場合にジャンプする命令
- `jl`: 第一引数が第二引数より小さい（符号あり）場合にジャンプする命令
- `jge`: 第一引数が第二引数以上（符号あり）の場合にジャンプする命令
- `jle`: 第一引数が第二引数以下（符号あり）の場合にジャンプする命令
- `jg`: 第一引数が第二引数より大きい（符号あり）場合にジャンプする命令
- `load_8`: メインメモリから8ビット値を読み込む命令
- `load_16`: メインメモリから16ビット値を読み込む命令
- `load_32`: メインメモリから32ビット値を読み込む命令
- `pload`: 永続メモリから値を読み込む命令
- `store_8`: メインメモリに8ビット値を書き込む命令
- `store_16`: メインメモリに16ビット値を書き込む命令
- `store_32`: メインメモリに32ビット値を書き込む命令
- `pstore`: 永続メモリに値を書き込む命令
- `mov`: 値を移動（コピー）する命令
- `neg`: 符号を反転させる命令
- `not`: ビットを反転させる命令
- `push`: スタックに値をプッシュする命令
- `pop`: スタックから値をポップする命令
- `call`: 関数を呼び出す命令
- `ret`: 最後の関数呼び出しからリターンする命令

## アセンブラ

### 乱数生成アセンブラ (キャンペーン: 32bit CPU用)

```asm
init:
    ; 初期シード (※このシード値は完全ランダムっぽい)
    in r1

loop:
    rnd_tmp1:
        ; temp1 = seed xor (seed lsr 13)
        lsr r2, r1, 13
        xor r10, r1, r2

    rnd_tmp2:
        ; temp2 = temp1 xor (temp1 lsl 17)
        lsl r2, r10, 17
        xor r11, r10, r2

    rnd_result:
        ; result = temp2 xor (temp2 lsr 5)
        lsr r2, r11, 5
        xor r13, r11, r2
        out r13

        ; 次の乱数生成に向けて乱数resultをシード値に設定
        mov r1, r13

        jmp loop
```
