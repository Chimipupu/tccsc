# CPUの仕様

## キャンペーン用: 8bit CPU

- レジスタ
  - `R0`: 即値用
  - `R1`: 計算対象A用
  - `R2`: 計算対象B用
  - `R3`: 計算結果用
  - `R4`: 汎用
  - `R5`: 汎用
  - `IN`: 入力
  - `OUT`: 出力
- 命令セット
  - mov,jmp,nop
  - 算術論理演算（add,sub,and,nand,or,nor）
    - R1とR2を計算してR3に結果が入る
  - 即値は「imm 5」とすれば5がR0に入る
